Browser extension setup

Record a meeting in your existing Brave or Chrome tab. No separate meeting browser or camera access is needed.

  1. Build the extension with npm run build:extension.
  2. Open brave://extensions or chrome://extensions, enable Developer mode, choose Load unpacked and select extension/dist from this checkout.
  3. Open Echo's extension setup page. Enable your meeting service and grant microphone permission if you want your voice included.
  4. In Echo Calendar or Settings, choose Connect an extension. Enter the code and Echo address in extension setup, then approve the named connection in Echo.
  5. Join normally, return to the meeting tab, open the toolbar popup, confirm participant permission and choose Start recording.

Live text is optional and needs an open Echo workspace with Turbo already downloaded. Recording continues offline; pending audio can be exported from the extension library.

Meeting mute or unknown controls excludes microphone. Uninstalling the extension or deleting the browser profile may remove unsynchronized audio. Transfer or export before removal.

Detailed installation, permissions, recovery and qualification instructions are in docs/browser-extension.md and docs/extension-qualification.md in this checkout.
