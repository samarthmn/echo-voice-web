Get Echo

Echo has two parts: a local app for your library and transcripts, and a browser extension for online meetings.

Qualification in progress

Echo desktop app

Initial targets are Apple Silicon Macs running macOS 14 or later, and Ubuntu 24.04 on x64.

The development packages include the runtime needed to use Echo. Speech models are downloaded when you choose them.

A signed, qualified installer is not available here yet.

Store submission pending

Meeting recorder extension

One Chrome Web Store package is intended for Brave and Chrome. Meet, Zoom Web and Teams Web are undergoing qualification individually.

Use your existing meeting login. The extension requires an explicit recording action and never attends a meeting by itself.

The store listing is not available yet.

Testing a development build?

Use the build supplied for your test and follow the repository's installation guide. A source ZIP is not an installer. Existing libraries should be backed up before testing a new version.

Read the candidate installation guideRead the qualification status

Before moving to a store installation

Finish recording and transfer or export all pending audio from the development extension. A new extension identity has separate browser storage; installing it does not move old recordings automatically. Keep the old installation until every recording is accounted for.
