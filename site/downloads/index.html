Get Echo

Echo has two parts: a locally served web app for your library and transcripts, and a browser extension for online meetings.

Qualification in progress

Echo web app

Run Echo's local server on your computer and open it in your existing Brave or Chrome browser. Your library stays on that computer.

Initial setup currently requires a source build and developer tools. Speech models are downloaded when you choose them.

Mac and Ubuntu browser qualification is in progress. No separate desktop application is provided.

Store submission pending

Meeting recorder extension

One Chrome Web Store package is intended for Brave and Chrome. Meet, Zoom Web and Teams Web are undergoing qualification individually.

Use your existing meeting login. The extension requires an explicit recording action and never attends a meeting by itself.

The store listing is not available yet.

Testing a development build?

Follow the repository's setup guide to build and start the local web server, then load the matching extension. Back up existing libraries before testing a new version. The extension does not install or start the server.

Read the web setup guideRead the qualification status

Before moving to a store installation

Finish recording and transfer or export all pending audio from the development extension. A new extension identity has separate browser storage; installing it does not move old recordings automatically. Keep the old installation until every recording is accounted for.
